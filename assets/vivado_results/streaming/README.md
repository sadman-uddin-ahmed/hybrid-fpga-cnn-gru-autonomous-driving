# Streaming FPGA Implementation Results

Selected Vivado and RTL-simulation evidence for the FPGA-native streaming/dataflow CNN implementation on the Nexys Video.

Included evidence covers:

- complete four-frame latency and numerical-verification regression
- final post-implementation FPGA resource utilisation
- routed timing closure at the 50 MHz CNN core clock

Additional generated Vivado reports and build artifacts are intentionally excluded from the public portfolio.
